# Jbxnu — Official Artist Website

Official artist website for **Jbxnu**, built from the approved master October artist website template.

## Features
- **Hero Video & Poster**: Custom 1080p web-optimized hero video and sharp poster frame extracted from Jbxnu's official visuals.
- **Discography & Stream Modal**: Direct multi-platform streaming links (Spotify, Apple Music, YouTube Music, Deezer, Amazon Music, Tidal, iTunes) for 5 featured releases:
  - *Scary Hours* (Single, Oct 30, 2026)
  - *Running* (Single, Apr 30, 2026)
  - *Bridge the Gap* (Single, Feb 12, 2026)
  - *After Party* (Single / All-Time Top Track)
  - *About You* (Single / All-Time Top Track)
- **Videos Section & Latest Video Feature**: 4 official YouTube videos:
  - *Bridge The Gap*
  - *CLOSURE FREESTYLE*
  - *Lifestyle*
  - *After Party*
- **Socials & Streaming Bar**: Verified icons and direct links for Spotify, Apple Music, YouTube, Instagram, and TikTok.

## Development & Deployment
```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Type check
npm run lint

# Build for production
npm run build

# Deploy to Cloudflare
npx wrangler deploy
```
